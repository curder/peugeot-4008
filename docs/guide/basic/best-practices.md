# 最佳实践 {#best-practices}

前面的几页介绍了标致 4008 各项基础操作的具体用法，本页收集一些不局限于单一操作的通用建议：

- 灯光相关：[外部灯光控制](/guide/basic/light-control)
- 巡航相关：[巡航系统](/guide/basic/cruise-system)
- 雨刮与视野相关：[雨刮器](/guide/basic/wiper)

## 上车前 {#before-driving}

- **绕车一周**：确认轮胎无明显亏气或异物、灯光与车牌完好、车身周围没有儿童或障碍物。
- **启动后检查仪表**：确认没有异常警告灯常亮，有警告灯点亮时先查清含义再行驶。
- **先调整座椅、后视镜与方向盘**：位置固定下来之后再出发，行驶中再调整会分散注意力。

## 行驶中 {#while-driving}

- **提前预判，减少急加速与急制动**：平稳驾驶既省油也更安全，乘员体验也更好。
- **保持可见的安全车距**：不依赖辅助功能判断距离，雨雾、夜间适当加大车距。
- **警告灯中途点亮先靠边**：在确保安全的前提下靠边停车确认，不要带故障继续行驶。

## 停车与锁车 {#parking}

- **窄路会车先收后视镜**：向后拉动驾驶位左侧后视镜调节区域的中间按钮即可收起，通过后再操作一次打开。
- **选择平整地面停车**：长期在斜坡停放会持续作用于悬挂与轮胎，开关车门也更费力。
- **锁车前确认车窗、灯光与用电设备已关闭**：避免蓄电池亏电导致下次无法启动。
- **长期停放**：尽量停在阴凉干燥处，定期启动车辆或行驶一段距离，保持蓄电池与轮胎状态。

> [!TIP] <strong>提示：</strong>
>
> 把常用操作养成固定习惯（例如上车先看仪表、锁车后再回看一眼灯光），比临时回忆操作步骤更可靠。

以上建议仅供参考，具体操作以车辆实际配置与随车说明书为准。

> [!WARNING] <strong>注意：</strong>
>
> 任何驾驶辅助功能都不能替代驾驶员的观察与判断，功能正常工作时驾驶员仍需对车辆安全负责。
